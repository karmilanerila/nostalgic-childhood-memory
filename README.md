A program that writes one nostalgic childhood memory — a single sentence, at most 280 characters — to `/output/entry.txt` for the [Make the AI Judge Feel Nostalgic: A Childhood Memory](https://make.fun/c/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363?ref=h379tqrk) bounty on make.fun.

The memory: a rainy afternoon in grandmother's kitchen, the rice cooker lid lifted, steam fogging her glasses, rain drumming on the tin roof, the ceiling fan clicking overhead — the whole small kitchen smelling like coming home.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
